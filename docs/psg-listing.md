# PSG (Productivity Solutions Grant) Listing Preparation

## Platform Overview for IMDA Submission

### Product Name

Arbor — AI-powered HR Advisory Platform for Singapore SMEs

### Product Category

Human Resource Management (HRM) — AI-Powered Advisory

### Product Description

Arbor is an AI-powered HR advisory platform that helps Singapore SMEs navigate employment regulations with confidence. It provides instant, source-cited guidance on the Employment Act, CPF, foreign manpower regulations, workplace safety, fair employment, and tax compliance.

### Key Capabilities

| Capability              | Description                                                                    |
| ----------------------- | ------------------------------------------------------------------------------ |
| AI Advisory             | Natural language Q&A with source-cited responses covering 6 regulatory domains |
| Compliance Health Check | Automated compliance scoring based on company profile                          |
| CPF Calculator          | Accurate CPF contribution calculations with OW/AW ceiling handling             |
| Leave Calculator        | Statutory leave entitlement calculations (annual, sick, maternity, etc.)       |
| Quota & Levy Calculator | Foreign worker quota and levy calculations by sector                           |
| Document Generation     | Employment contracts, KETs, payslips, HR policy templates                      |
| Regulatory Alerts       | Proactive notifications when regulations change                                |
| Multi-Client Support    | Consultant view for managing multiple SME clients                              |
| Trust & Transparency    | Every response shows source citations and authority level                      |

### Target Users

- Singapore-registered SMEs (1-200 employees)
- HR practitioners in SMEs
- HR consultants serving SME clients
- Business owners managing HR directly
