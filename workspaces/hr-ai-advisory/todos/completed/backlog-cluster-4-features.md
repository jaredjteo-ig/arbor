## TODO-B01 — PDF/DOCX document generation ✅ fixed

- **Priority**: Critical
- **Source**: Round 11, F-C1
- **State at start**: PDF + TXT supported via `_generate_document_pdf`
  (reportlab); DOCX missing entirely.
- **Fix**:
  - Added `_generate_document_docx(title, content, company_name)` in
    `src/hr_advisory/api/routers/document.py` using python-docx.
    Mirrors the PDF path's section-parsing rules so PDF and DOCX output
    look the same — same headers, headings, sub-items, signature lines,
    footer with "Generated by Arbor HR Platform | <date>".
  - Extended `download_document` to accept `format=docx`. Returns
    `application/vnd.openxmlformats-officedocument.wordprocessingml.document`
    with the appropriate Content-Disposition.
  - Frontend `documents/[id]/generate/page.tsx`: `handleDownload` now
    accepts `"pdf" | "docx"`; the UI offers two download buttons.
- **Regression tests**: `tests/regression/test_b_cluster_4_features.py`
  - `test_b01_docx_export_produces_valid_word_file` — generates a DOCX,
    parses it as a zip, validates body + footer XML contents.
  - `test_b01_download_endpoint_accepts_docx_format` — pins the format
    allow-list `("pdf", "docx", "txt")` in the route.
